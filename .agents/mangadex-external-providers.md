# MangaDex external providers

Validation comparison performed against `.agents/skills/validate-changes/SKILL.md`. This is a research doc, no code changed.

All hosts below were checked live against `api.mangadex.org` on 2026-09-20 unless marked otherwise. Shapes come from real `externalUrl` values, not docs.

## How externals work on MangaDex

Some titles host no files on MangaDex at all. Their chapters are link-only pointers to official publishers. On the API this shows as a chapter with `externalUrl` set and no page hash. The feed endpoint hides these by default. Pass `includeExternalUrl=1` to see them.

Three quirks shape any reader integration:

- Placeholder pages. Some external chapters report `pages:1`, others `pages:0`. The `1` is an autogenerated info card MangaDex leaves behind, not readable content. Key off `externalUrl != null`, never off page count.
- Shared URLs. Several chapter entries can point at one external URL. Chapters 1 through 4 of Futsuu no Keionbu all resolve to the same MangaPlus viewer id. Dedupe by external URL before downloading.
- Tracking params. Most hosts append `utm_source=mgd` or similar. Strip query strings before matching shapes.

## Live hosts

| Host | URL shape | Uploader group | Volume and notes |
|---|---|---|---|
| `mangaplus.shueisha.co.jp` | `/viewer/<numericId>` | MangaPlus `4f1de6a2` | Bot-linked, highest volume. Example: Oshi no Ko ch 1-166 |
| `kmanga.kodansha.com` | `/title/<titleId>/episode/<episodeId>` | K-Manga `7c5fb223` | Growing. US region lock. Example: Bakemonogatari ch 1-3 |
| `namicomi.com` | `/c/<shortId>` | NamiComi `9771ebfe` | 10,231 entries. Self-published creators, multi-language |
| `comikey.com`, `br.comikey.com` | `/read/<series>/<guid>/chapter-<n>/`, webtoons use `/episode-<n>/` | Comikey `8d8ecf83` | 4,327 entries. Paywalled past the free chapters |
| `j-novel.club` | `/read/<slug>` | J-Novel Club `4ba19c33` | 674 entries. First-chapter-of-volume previews only, never full runs |
| `omoi.com` | `/series/<slug>/read/<uuid>` | Omoi `5fed0576` | 212 entries. Official and verified. This is Azuki rebranded |

Locale subdomains count as the same host. The `br.comikey.com` entries follow the same path shape with `episode-<n>` for webtoons.

## Legacy, superseded, and absent

- `azuki.co` is superseded by the Omoi rebrand. A full Omoi title feed showed only `omoi.com` links, no surviving `azuki.co` entries in the sample. TachiyomiSY's Azuki handler still targets `azuki.co` and `production.api.azuki.co`, so treat it as stale until proven otherwise.
- Tapas has an official linker group (`1f05f2cb`) but zero external chapters. Placeholder, no live entries.
- Checked and absent: INKR (official group exists, zero externals), MangaPlanet (no group at all), WEBTOON (no linker group), Alpha Manga (nothing found).

## Current gap in this repo

`extractors/mangadex.js:417` throws on chapters with `externalUrl`, and `:610` skips them silently in title feeds. An Oshi no Ko series import therefore drops every chapter with no trace. Any provider work starts here.
