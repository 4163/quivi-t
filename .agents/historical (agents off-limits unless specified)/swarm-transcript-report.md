## 2. Stage 5: eight execution-breaking traps caught after Stage 4 agreed

Stage 4 ended with two `Gemini 4 Neon (High)` authors (`roadmap-author` and `roadmap-telemetry`) unanimously satisfied (`#155`, `#156`). Stage 5 then unleashed a fresh `final-auditor` plus the original Stage 3 split reps against live source code. Five splits passed immediately (`S05`, `S08`, `S09`, `S10`, `S11`), while `final-auditor` (`#164`) and six frontend splits (`S01`, `S02`, `S03`, `S04`, `S06`, `S07`) filed **`[Block]`** verdicts that caught bugs which would have broken mid-refactor execution:

1. **Fatal ESM `SyntaxError` in `options.html` (`s01-state-arch` `#169`):** `#U05-16` deleted `export let previewing` from `src/js/shared/configPreview.js:4`, but live `src/js/options/options.js:8` imports `{ previewing, ... }` and is not touched until `#U07-06`. That would have crashed `options.html` and failed `06-configuration.e2e.js` in both `U05` and `U06`. **Fix:** Keep `export let previewing` alongside `isPreviewing()` during `U05` and drop it atomically in `#U07-06`.
2. **DI cutover breaking live E2E in `U05` (`final-auditor` `#164` B2, `s01-state-arch` `#169`):** `#U05-01/02/03/05/06/10/11/18/19` stripped browser/Tauri defaults from `core.js`, `fsUtils.js`, `actions.js`, `navigationHistory.js`, `archiveImageCache.js`, `workspaceControls.js`, and `workspaceSession.js` while deferring `main.js` wiring to `U06`, yet `#U05-TB` runs live E2E `01` through `07`. Also `#U05-02` accidentally told pure `core.js` to await DOM helper `syncShellBackground()`. **Fix:** Keep guarded `typeof window !== 'undefined'` browser fallbacks and a pure `onBeforeShow` hook during `U05`, removing each fallback explicitly in `#U06-05`, `#U08-13`, and `#U09-02`.
3. **Collapsed virtual scroll height in `#file-list` (`s02-html-css` `#168`):** Converting `<div class="scroll-spacer">` to `<li class="scroll-spacer">` in `#U06-02` caused `main.css:1288-1308` (`#file-list li { position: absolute; ... }`) and `:1555` (`height: var(--thumbnail-row-height)`) to override `.scroll-spacer`, collapsing `#file-list` scroll height (`filePanel.js:1862-1865`). **Fix:** Add `:not(.scroll-spacer)` on `#file-list li` rules in `file-panel.css`.
4. **CSS custom-property shadowing across `U06 -> U08` (`final-auditor` `#164` B3, `s04-panel-perf` `#167`, `s02-html-css` `#168`):** Re-scoping `--panel-*`, `--col-*-w`, and `--file-grid-cols` from `:root` to `#file-panel` in `U06` shadowed `:root` writes from `filePanel.js:142,552,556,3399` (which is not updated until `U08`). **Fix:** Keep those tokens on `:root` inside `file-panel.css` during `U06`, then re-scope them to `#file-panel` / `#workspace` atomically in `#U08-02`.
5. **Parallel DAG deadlock around `options-active-tab` (`s03-options-perf` `#166`, `final-auditor` `#164` B3):** `#U06-05` deleted `main.js:64` (`localStorage.removeItem('options-active-tab')`) before `#U07-06` switched `options.js:236,245` to `sessionStorage`, regressing `06-configuration.e2e.js`. Moving `main.js:64` deletion to `U07` was impossible because `U07 \|\| U08` (and `U08` edits `main.js`), and moving it to `U10` was also unsafe because `U07 \|\| U10`. **Fix:** Switch `options.js:236,245` to `sessionStorage` atomically inside `#U06-05` (strict ancestor of `U07`..`U11`).
6. **Implicit `U04 \|\| U06`/`U07` DAG collision (`final-auditor` `#164` B1):** `U06` listed `Depends on: U05` without `U04`, silently allowing `U04` to run alongside `U06` or `U07` even though all three edit `e2e/specs/06-configuration.e2e.js`. **Fix:** Set `U06` `Depends on: U04, U05`.
7. **Missed live callers & stale post-`U06` paths (`s06-strip-perf` `#173`, `s07-gpu-perf` `#172`):**
   - Moving `computeSlotHue` out of `keybindDomain.js` in `#U10-10` broke live caller `keybindDomain.js:68` (`getConflictColors`) in `options.html`.
   - `#U10-07` (`ViewerAudio.bindVideo`) omitted `viewerRender.js:237` (`incoming.muted = true` clobbering user audio state) and `viewer.js:35-38`; `#U10-06` omitted adding `onManhwaMaxWidth(fn)` in `fsUtils.js`.
   - `#U11-10` targeted `menubar.js` even though `#U06-10` had already moved `FILTER_LABELS` / `scalingLabels` into `menubar/viewMenu.js`.
   - Dropping `dx/dy/dw/dh` aliases in `#U11-07` missed `viewerPipelines.js:2000-2001` and `mocha/quadCompositor.test.js:194-201,342`, and `comparisons.md:574` counted `21` leaked shaders instead of `42` (`vs` + `fs` across 21 passes).
8. **23 non-runnable PowerShell commands & 0-match Cargo filters (`final-auditor` `#164` B4/B5 + all FE reps):** `roadmap.md` contained 23 bash-only `{a,b}` brace expansions (broken on Windows PowerShell and rejected by single-scenario `e2e/replay-diagnostics/cli.js:204-206`), plus Cargo filters `encoding`, `config_tests`, and post-`U02` `format_tests` that matched **0 tests** against live `cargo test --lib -- --list`. **Fix:** Expanded every spec/scenario into standalone runnable commands and updated Cargo filters to `zip_decodes_`, `config::tests`, `formats::tests`, `windows::tests`, and `ico::tests`.

## 3. Surprising bugs and measured performance discoveries

Beyond standard decoupling work, Stage 3 agents ran live Node benchmarks and traced low-level GPU, Win32, and archive hot paths to uncover concrete waste:

### Measured frontend hotspots (live Node benchmarks)

| Surface | Bottleneck found | Measured impact |
|---|---|---|
| `src/js/fsUtils.js:89-94` (`S01` `#57`) | `_formatDate` constructs `new Date(ms).toLocaleDateString()` per item instead of a module-scoped `Intl.DateTimeFormat()`. | `77.93 ms` -> `2.58 ms` at 2,000 entries (**30.1x faster**). |
| `src/js/services/sorting.js` + `lifecycle.js:8` (`S01` `#57`) | `naturalPagePosition` re-sorts/scans linearly, and `lifecycle.js:8` calls it synchronously on **every** `Core.onStateChange` (every arrow-key step and toggle). | `21.82 ms` -> `2.23 ms` at 2,000 filenames (**9.8x faster** with cached `Intl.Collator`, O(1) via `WeakMap` cache). |
| `src/js/options/keybindUi.js:317-319` (`S03` `#47`/`#63`) | `getConflictColors(keybinds)` runs inside `slots.forEach` (**64x per render** instead of once before the loop). | `5.885 ms` -> `0.073 ms` in Node (**80.6x faster**). |
| `src/js/urlLoader.js:395-408` (`S05` `#72`) | `DownloadQueue._findItem` + workspace snapshot does `O(N^2)` scans per queue event. | `91.23 ms` at `N=500` items. |
| `src/js/shared/svgUtils.js` (`S05` `#72`) | Baseline sanitization/entity cost measured on live workload (`632 KB` / `400` entities). | `10.54 ms` baseline (guarded by explicit entity/byte caps). |
| `src/js/urlLoader.js:847,921` (`S05` `#72`) | `_resolveDepGraph` allocates dependency Blob URLs **before** checking `_extractorCache.get(cacheKey)`, leaking Blob URLs on every cache hit. | Unbounded Blob URL leak across repeated extractor imports. |

### GPU, rendering, and diagnostic surprises

- **100% dead GPU passes in Anime4K (`S07` `#85`/`#90`):** Passes 0-2 in `src/js/services/filters/anime4k/chains.js` (`De-Ring-Compute-Statistics`, `De-Ring-Clamp`, unnamed clamp) write `STATSMAX` and `pass_2_tmp`, yet Pass 3, Pass 4, and the final residual pass all read `input: "source"`. Those 3 passes (~`100 MB` of full-res FBO VRAM at 4K) are never read anywhere. Removing them preserves bit-identical output while cutting `FAST` from `11` to `8` passes (`-27%`) and `NORMAL` from `20` to `17` passes (`-15%`).
- **42 leaked WebGL shaders + idle 60-144Hz decode loops (`S07` `#44`/`#85`):** `glRuntime.js:45-58` never calls `gl.deleteShader()` on `vs` and `fs` after linking (`42` leaked shaders on 21-pass chains). Meanwhile `viewerPipelines.js:987` calls `await decoder.decode({ frameIndex })` on **every 60-144Hz rAF before checking `needsRender`**, decoding and immediately closing frames when idle; the legacy SVG pump (`:874`) also spins rAF forever on static SVGs.
- **Silently broken diagnostic probe (`S06` `#76`):** `e2e/replay-diagnostics/probes/viewerPipelineProbe.js:19-20` runs `parseFloat("calc(-50% + 123px)")`, which always evaluates to `NaN`, rendering the `ty-teleport` anomaly check (`:244`) completely inert.
- **Unbound archive thumbnail re-decodes (`S04` `#62`):** Archive thumbnails in `filePanel.js` were never marked cached (`L1966-1971,2147,2349-2353`), triggering repeated re-decodes on scroll, while `commitPendingThumbnails` scheduled uncancellable per-item `setTimeout(..., 10 + orderIdx*15)` queues.

### Rust backend concurrency, Win32, and I/O surprises

- **30-second global archive write-lock stalls (`S09` `#94`/`#96`/`#97`):** `commands/animation.rs:41-44,63-66` held `RwLock<ArchiveCache>::write()` across disk reads and a `30s` `Condvar` wait, blocking concurrent `quivit://archive/` image loads; `SingleArchiveCache::drop` also raced `spawn_temp_extractor` with `Relaxed` atomics so cancelled extractors could recreate deleted temp directories.
- **Full-archive TAR scans and 256 KiB SVG scans on JPEGs (`S09` `#94`/`#96`):** `tar.rs:72-77` used an unbuffered file + `archive.entries()` to sequentially read every byte of an entire TAR (e.g., `92 MB`) just to list filenames; `formats.rs:353` scanned `256 KiB` byte-by-byte for `<svg` on every JPEG/BMP/TIFF/ICO; `read_media_dimensions_from_path` heap-allocated `64 KiB` per file (`64 MB` per 1,000 files); and `thumbnails.rs:244-249` opened the file on disk before checking already-in-memory `has_alpha`.
- **Per-32KiB-chunk stat storm + forever 1 Hz watchdog (`S10` `#95`/`#100`):** `download_to_file` (`network.rs:332-338`) called `ensure_library_root_writable` (2 `stat`s) on every 32 KiB network chunk; `platform/drop.rs:239-264` woke a `1 Hz` watchdog forever even while idle and never stopped on `shutdown()`; `platform/temp_archive.rs:330` mutated `SetProcessWindowStation` and ran duplicate `EnumWindows` + `EnumDesktopWindows` scans; `image_import.rs:135` read up to `8 MiB` of SVG text solely to check `!text.is_empty()`.
- **Explorer preview double 128 MiB fetch & STA bottleneck (`S11` `#108`/`#109`):** `image_pane.rs:450` cloned up to `128 MiB` per `/media` request, and `preview_player.js:149-169` buffered the full image via `arrayBuffer()` + `ImageDecoder`, only to discard it on static images (`frameCount < 2`) and set `image.src = '/media'` (double fetch + double decode). `thumb_server.rs` used STA + a global `DECODE_LOCK`, serializing every Explorer folder thumbnail on one thread, while `com_server.rs` had 5 `.lock().unwrap()` calls across `extern "system"` COM boundaries and recreated GDI `HBRUSH`/`HPEN` objects 10-15x per frame.
- **Roaming-to-portable self-recreation bug (`S08` `#81`/`#83`):** `config.rs:620` deleted `custom_css.css` a second time after `remove_roaming_files`, causing roaming-to-portable migration to recreate the roaming directory it had just emptied; `lib.rs:96-99` also ran recursive file watchers and synchronous `cleanup_orphaned_temp_dirs` on the main setup thread before first paint, parsing `quivit_config.json` 3-5 times on startup.
