# Refactoring roadmap (`refactor/decoupling-and-perf`)

This document is the present-state execution plan for decoupling, architectural compliance, and performance work across QuiviT. Every checklist item traces directly to an `[Agreed]` Stage 3 audit finding under `.agents/major-refactor/audit-01-*.md` through `audit-11-*.md` and the cross-split matrix in `.agents/major-refactor/cross-split-seams.md`.

## Execution rules and state markers

- **State markers:** `[ ]` pending, `[~]` in progress, `[-]` agent-verified complete, `[x]` user-verified complete, `[o]` deferred with mutual item links.
- **Test-creation rule override for refactor execution:** The `AGENTS.md` rule against creating new test suites mid-implementation is lifted for this roadmap. Every execution unit starts by expanding unit, E2E, or diagnostic coverage in Telemetry A against pre-refactor code before modifying production files.
- **Telemetry A and B commit gates:** Every unit runs Telemetry A (add missing tests/probes, capture baseline JSON under `.agents/major-refactor/telemetry/uXX-baseline-<suite>.json`, pause for user commit), applies production refactors, and closes with Telemetry B (update imports/contract checks for extracted seams, capture post JSON under `.agents/major-refactor/telemetry/uXX-post-<suite>.json`, record parity and measured gains in `.agents/major-refactor/telemetry/comparisons.md`, pause for user commit).
- **No automated git commits:** Pause at every Commit gate A and Commit gate B for manual commit. Do not run `git commit` or `git push`.
- **Resolutions locked across all units:** Keep DevTools enabled in release app windows (`Cargo.toml:25`, `lib.rs:80`, `windows.rs:147,251,295`) per `README.md:150` while keeping Explorer preview pane DevTools gated on `cfg!(debug_assertions)` (`image_pane.rs:415`) (R1). Replace `"csp": null` with explicit runtime-verified directives and keep `assetProtocol` enabled (R2). Delete dead `#viewer-loading-frame` and `.viewer-img.is-placeholder`, and add `.tabs.is-measuring-width` for `windowFit.js` (R3). Align `centerListItem`, `FsUtils.buildAudioSrc`, `activeKeys`, `computeColumnComposite`, `viewerPipelineProbe.js:19-20`, spacer CSS vars, and `diagnosticsContract.test.js` across S01/S06/S07 (R4). Keep disjoint Rust modules (`commands/{config,windows,icons}.rs`, `platform/{gdi,associations,shell}.rs`, `library.rs`, `network.rs`) and `.tmp` watcher filters (R5). Remove 4 dead IPCs (72 down to 68 active) (R6). Remove `lib.rs:17-20` wildcard imports and mount all Rust tests under `src-tauri/src/tests/` via `#[path]` (R7).

## Four test and diagnostic suites

1. **Mocha frontend unit tests:** `npm run mocha` (`mocha/*.test.js`; `package.json` has no `npm test` script).
2. **Rust backend unit tests:** `cargo test --manifest-path src-tauri/Cargo.toml` (with optional `<filter>`, or `cargo check --tests --manifest-path src-tauri/Cargo.toml` during iteration).
3. **WebdriverIO desktop E2E tests:** `npm run e2e -- --spec <file>` (re-run with `--agent` only if an elevated shell is reported).
4. **Replay diagnostics:** `npm run diagnose -- <scenario>` against recorded `e2e/scenarios/<scenario>.json` files.
