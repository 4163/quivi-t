Minimal User Sequence:
1. Open a folder containing images along with a parent directory (..) or preceding folders.
2. Enable Manhwa view mode (shortcut 'm').
3. Detach the File List into a secondary window via 'Window -> File List: Detached Window'.
4. In the main window's viewport, scroll the manhwa strip to the very top, then pan upward further, or press Home (jumpManhwa(-1)).
5. Inspect the scroll position of the detached File List window.

Expected Behavior:
In combined mode, when the user scrolls or jumps past the top of the manhwa strip, triggerRevealListTop() executes revealListTop(), which scrolls fileListUl.scrollTop to 0 so the parent directory item (..) is visible to the user, and pauses strip navigation at the container boundary. This reveal must happen on the visible File List in the secondary window.

Actual Behavior:
triggerRevealListTop() calls the function registered in main.js:259 (setRevealListTop(revealListTop)), which executes revealListTop() from filePanel.js on the main window's DOM. In detached mode, the main window's #file-panel is hidden via CSS (display: none;), while the visible file list is in the secondary native window workspace-file-list.
The call sets fileListUl.scrollTop = 0 on the hidden main DOM element and has zero effect on the visible detached file list.
Furthermore, because the hidden main element's fileListUl.scrollTop is already 0, revealListTop() returns wasAtTop: true. In manhwaStrip.js:2377, _revealBeforeLeavingStrip evaluates !triggerRevealListTop() as false, prematurely failing to hold at the top boundary.

Complete Causal Chain:
1. In viewer.js:29-32, _revealListTopOnPan(dy) detects dy > 0 && isManhwaStripActive() && isStripAtTop() and calls triggerRevealListTop().
2. In manhwaStrip.js:3130-3132, triggerRevealListTop() delegates to _onRevealListTop().
3. In main.js:259, setRevealListTop(revealListTop) wires this callback directly to revealListTop from filePanel.js.
4. In filePanel.js:3097-3102, revealListTop() mutates the local document node fileListUl.scrollTop = 0.
5. In detached mode, :root[data-workspace-surface="main"] #workspace[data-file-list-position="detached"] > #file-panel is hidden with display: none (main.css:496).
6. workspaceControls.js:62 connects strip RPC handlers (alignListItemTop, alignListItemBottom, navigateManhwa, pageStrip, jumpManhwa), but omits revealListTop.
7. No RPC call or event is sent to workspace-file-list. The visible detached file list never scrolls to reveal the parent folder entry.
